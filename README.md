# AstrBot 正则自动回复 v1.0.0

根据收到的文字消息匹配正则表达式，并回复预设内容。规则在 AstrBot 插件配置页中维护，不需要修改 Python 代码。

## 功能

- 多条规则，按优先级从高到低匹配；每条消息只回复第一条命中规则。
- 匹配模式：整句匹配 `fullmatch`、包含匹配 `search`、从开头匹配 `match`。
- 忽略大小写；可分别设置群聊、私聊或全部会话。
- 回复模板支持 `{0}`（完整匹配文本）、`{1}`/`{2}`（捕获组）和 `{name}`（命名捕获组）。
- 默认忽略 `/`、`／`、`!`、`！` 开头的命令消息，避免干扰常见命令。
- 使用 `regex` 库的匹配超时，并限制正则、回复和消息长度，减少错误规则拖慢机器人处理的风险。
- 命中后默认停止后续处理，避免 AI 对同一条消息再回答；如果需要两者都回复，可以关闭此选项。注意，开启后也会阻止后续事件处理器。

## 安装

1. 在 AstrBot WebUI 的插件管理中选择从文件安装，上传本 ZIP；或者解压后把 `astrbot_plugin_regex_reply` 文件夹放到 `data/plugins/`。
2. 等待依赖 `regex` 安装完成，并确认插件加载成功。
3. 打开「插件」页面中的「正则自动回复」配置，编辑 `rules`，保存后重载插件。

适配 AstrBot `>=4.17.0`，支持 `aiocqhttp`、QQ 官方机器人和 QQ 官方 Webhook。部署方式为 Docker 时，配置由 AstrBot 持久化管理，不需要修改现有容器挂载。

## 配置示例

### 1. 只匹配完整问候

- 正则：`^(你好|您好|嗨)$`
- 模式：`fullmatch`
- 回复：`你好呀～有什么我可以帮你的？`

### 2. 从句子中提取名字

- 正则：`^我叫(.+)$`
- 模式：`fullmatch`
- 回复：`你好，{1}！`

发送「我叫小明」，回复「你好，小明！」。

### 3. 匹配包含特定短语的消息

- 正则：`.*今天好累.*`
- 模式：`fullmatch`
- 回复：`辛苦啦，记得休息一下。`

也可以直接把匹配方式设置为 `search`，并把正则改成 `今天好累`。

## 重要说明

- 优先使用 `fullmatch` 或带 `^`、`$` 的整句规则；不建议配置 `.*` 这类会匹配所有消息的宽泛正则。
- 如果开启「命中后停止后续处理」，命中规则后不会再走后续 AI 回复，并且后续事件处理器也不会继续执行。
- 配置保存后如果未立即生效，请在插件管理页重载插件。
- 插件只读取消息的纯文本部分；图片、语音等非文本内容不会被解析为文字。
